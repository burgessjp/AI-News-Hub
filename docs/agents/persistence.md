# 持久化

> 面向 AI 编码代理的领域约定，从根 `AGENTS.md` 拆出。加设置项、动 Room 表 / DataStore 键 / 缓存前先读本文。

- DataStore：`display_prefs`（主题 / 动态取色 / 字体族 / 字号档位 / 源模式 / 应用内语言 `language` / 搜索历史 / 信息源顺序 `source_order` / 关注关键词 `followed_keywords`（「我的关注」订阅词，≤20 个，端上 `FollowMatcher` 过滤，增删只重算不发请求）/ 每日更新通知开关 `daily_notify` 与调度状态 `last_notified_overview_at`、`last_notify_check_at`——后者为自查链上次运行时刻，设置页开关下显示「上次检查」，用于区分链被厂商后台限制拦住与档内没新数据）、`ai_prefs`（全局 AI 服务配置 + 按「模型 × 月」聚合的 token 用量）。
- Room（`ainewshub.db`，version 5，`fallbackToDestructiveMigration` 兜底 + 显式 `MIGRATION_1_2`/`MIGRATION_2_3`/`MIGRATION_3_4`/`MIGRATION_4_5`）：浏览历史 + 收藏 + 本地搜索索引（search_items 表，v3 新增；升级走 Migration 保住老数据）。**阅读进度（「继续上次阅读」）**：browse_history 的 `progress` 列（0-100 百分比，v5 新增），WebView 滚动节流写 Ref、`onDispose`/`ON_PAUSE`/站内跳转前经 Repository 的 fire-and-forget 作用域落库（专用 `updateProgress` 只动该列，不碰 visitCount/visitedAt；`record()` 的 copy 不覆盖旧值）；重开同一 URL 时 `progressOf` 读取，8–92 区间才浮「继续上次阅读」chip；用户勾选清空浏览历史连进度一起清（既有语义）。**收藏（稍后读）**：入口为 WebView 顶栏星标（toggle 当前真实 URL，全 App 链接都经 `openUrl` 进 WebView 故全源覆盖），`Page.Web` 带 `source` 标签随收藏落库；管理页为「更多 → 收藏」二级页（`Page.Favorites`，镜像浏览历史三件套：`FavoriteEntity/FavoriteDao/FavoritesRepository` + `FavoritesViewModel/FavoritesScreen`）；缓存清理任何开关都不触碰 favorites 表。**浏览历史兼任已读状态**：`observeReadUrls()`（url 全表 → Set）供各列表「已读弱化/只看未读」判定（`ui/components/ReadState.kt` 的 `rememberReadUrls()`），删除单条历史 = 恢复未读。记录点除 `openUrl`（WebView 打开）外，还包括**点进详情页**（`PageView.onItemClick`，记 permalink 优先 URL）与**点进 HN 评论页**（`PageView` HN 分支，记 discussionUrl）——「点开过即已读」，这些条目同样出现在浏览历史（语义 = 我点开过的文章）。**本地搜索索引**：`SearchItemEntity`（url 主键 + title/summary/source/indexedAt，`SearchIndexRepository` 单例 object，`App.onCreate` init），各源 Repository 取数成功后回填（key = 列表行点击时传给 `openUrl` 的同一 URL，保证与已读判定联动），只收录用户浏览过的批次数据、90 天抽样清理；由**独立的「本地搜索」二级页**消费（`Page.LocalSearch` / `LocalSearchScreen`，总览顶栏入口），LIKE 查询（FTS 默认分词不支持中文故不用 FTS），与「全部动态」页的联网搜索页（aihot 第三方 API）互不共用页面与逻辑；缓存清理随 cacheDir 全清（表本身可随时由浏览重建）。
- HN 列表缓存、翻译缓存为 `cacheDir` 下 JSON 文件；**归档数据磁盘缓存** `cacheDir/archives/`（断网兜底：仅传输层失败读盘，64MB 上限最旧淘汰 + 读取 7 天时效，见 data-layer.md「归档取数」）。
- 桌面小组件缓存为 SharedPreferences `hot_now_widget`（今日热点列表 JSON + 时间戳，KB 级，`CacheManager` 不涉及）。
