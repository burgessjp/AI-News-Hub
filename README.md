## Why use it

- **Read the whole AI world in one screen** — Aggregates 8 high-quality sources (HackerNews, GitHub Trending, HuggingFace Papers, Product Hunt, and more) so you can catch up on the day in one app.
- **AI does the heavy lifting** — A companion pipeline pre-generates Chinese bullet points for every source, a cross-source "Today's Top 10", and a keyword-trends leaderboard every day. Open and read instantly, zero waiting. Breaking items are flagged.
- **You control the sources** — long-press and drag the source tiles to customize the order.
- **Your AI key stays yours** — Runtime AI features like full-page translation ship with no built-in key. You bring your own provider (DeepSeek / Zhipu GLM / any OpenAI-compatible service), stored only in app-private storage.
- **Read everything in-app** — Every link in the app opens in the built-in WebView with Reader Mode and full-page translation. No jumping out to an external browser.
- **Home screen widget** — A "Today's Hot" widget that auto-refreshes every 30 minutes; jump straight to the highlights from your home screen.

## 📖 Overview

**AI News Hub** aggregates multiple high-quality AI sources — HackerNews, GitHub Trending, HuggingFace Papers, Product Hunt, stormzhang AI, The Rundown AI, OpenAI × Anthropic updates, plus the "AIHot Picks" and AI Daily from `aihot.virxact.com` — and layers on top of them "Today's Top 10", "keyword trends", "Chinese summaries", and "full-page translation" so you can finish the day's AI news in a single app.

- Tech stack: Kotlin + Jetpack Compose + Material 3
- Single-module project, package name `com.peng.ainewshub`
- Targets Android 7.0 (API 24) and above

## ✨ Core features

### Two root tabs

| Tab | What it does |
|-----|--------|
| **Today** | A single vertical daily paper. The digest hero opens with an edition line (date · morning/evening edition · data as of), followed by "Today's Top 10" — both pre-generated by the pipeline; items the AI flags as breaking get a red inline tag and sort to the top, and long digests fold by default. Below Top 10 sits a collapsed "My follows" row (your keyword-subscription hits, expandable in place, not rendered when you follow nothing), then AI summary sections for all 8 archived sources — each previewing up to 3 entries with a "view all" link and a "new content" dot until you view that source. Tap any entry to open the original in the built-in WebView, instantly. |
| **More** | Settings, AI service config, source hub, favorites (read-later), Past Issues (pick a date and read that day's full paper on one page), AI Daily archive, About, etc. |

**Hotwords page** (secondary page entered from the Today masthead): the cross-source keyword leaderboard — window hit counts, a mini trend line, and up/down / rank-change markers, computed from the last 14 days of snapshots with at most one AI-refinement pass per batch (falling back to pure statistics on failure). Tap a keyword to expand its representative articles — follow it in one tap or search all its hits; the word cloud and keyword history by date live here too.

The Today tab and the Hotwords page support **pull-to-refresh**, which bypasses the archive cache to pick up the pipeline's latest batch right away.

### Browse area (More → Sources)

8 source tiles, each with its own detail page:

- **HackerNews** — Top Stories leaderboard + expandable comment trees (comments fetched live from the Firebase API)
- **GitHub Trending** — filter by repo language / time window
- **OpenAI × Anthropic** — aggregated official updates from two leading AI labs
- **HuggingFace Papers** — trending papers leaderboard
- **Product Hunt** — daily product leaderboard (archive mode only)
- **The Rundown AI**, **stormzhang AI** — English / Chinese AI newsletters
- **AIHot Picks** — "Today's Hot + Picks TOP20" from the third-party service aihot.virxact.com

The 5 stable sources (HackerNews / GitHub Trending / HuggingFace Papers / The Rundown AI / stormzhang AI) always read from the companion data pipeline's archived snapshots.

### AI capabilities

- **AI Chinese summaries** (pipeline pre-generated): the day's bullet points for every archived source, instant on open
- **Today's Top 10** (pipeline pre-generated): cross-source comprehensive analysis; breaking items get a Breaking badge
- **Full-page translation** (runtime, user-supplied key): "Translate this page" in the built-in WebView and the "译" entry in the system text-selection menu
- **Usage tracking**: tokens aggregated by "model × month", with cost estimates from list prices

### Built-in WebView

Every link in the app opens in-app, never in an external browser:

- Reader Mode (injects Mozilla Readability to extract the article body)
- Full-page translation (side-by-side with the original, draggable half/full-screen panel)
- Star any page from the top bar to save it to Favorites (read-later)
- Resume reading: the scroll position of every long article is remembered per URL — reopen one and a chip offers to jump back to where you left off (progress also shows as a badge on history rows)
- The bottom toolbar auto-hides while scrolling down and comes back on scroll up
- Web downloads, HTML5 video fullscreen, long-press image/link actions
- Font size follows the system setting

### More

- **AI Daily** and **historical archive** (browse back by date)
- **On-device search**: a dedicated page (the Search entry in the Today masthead) querying a local index built automatically as you browse the 8 sources — search titles and summaries, read items dim, results open the original page; the Hotwords "see all hits" action and word-cloud taps hand a keyword straight to this search
- **Online search**: from the All-feeds page top bar (third-party AIHot API), with local search history + trending-word hints
- **Read state**: opened items dim across every feed, with an "Unread only" filter on the items list (delete a history entry to un-read)
- **Offline fallback**: archive data is written through to a disk cache, so a cold start without network still shows the last fetched content
- **Browsing history & Favorites** (stored locally in Room; star any page from the built-in WebView to read it later)
- **In-app update check & install** (About page) against GitHub Releases — the "new version" bottom sheet downloads the APK with live progress (cancellable) and hands off to the system installer, falling back to the Release page on failure; plus `ainewshub://` deep links (`web?url=…`, `tab/<today|more>` with legacy names permanently mapped — overview/summary/follows→today, trends/hotwords→hotwords page, `settings`) for browsers, QR codes and automation tools
- **Theme**: dark mode and font size presets (the whole app is set in a serif "paper-ink" typographic style)
- **Languages**: switch between Simplified Chinese and English

## 🛠 Build from source

### Requirements

- JDK 17
- Android Studio (any recent version supporting AGP 8.7.3) or command-line Gradle only
- Android SDK Platform 35, Build-Tools 35.x

### Debug build

```bash
git clone <this-repo-url>
cd AI-News-Hub
cp local.properties.example local.properties   # edit the SDK path if needed (if no sample exists, set sdk.dir manually)
./gradlew assembleDebug                        # output: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug                         # install directly onto a connected device/emulator
```

### Release build

Release builds require local signing material (**never committed to the repo**):

1. Place a `keystore.properties` at the project root:

   ```properties
   storeFile=app/release.jks
   storePassword=***
   keyAlias=***
   keyPassword=***
   ```

2. Place the matching `release.jks` under `app/`.

3. Run:

   ```bash
   ./gradlew assembleRelease
   # output: app/build/outputs/apk/release/app-release.apk
   ```

CI (GitHub Actions) restores the keystore from repository secrets; tagging `v*` produces a Release automatically.

## 🔑 Configure the AI service

AI News Hub's runtime AI features such as full-page translation **ship with no built-in key** — you provide one in-app (pre-generated content like summaries and Today's Hot needs no key and is instant):

Open the app → **More → AI Service**, pick a provider preset (DeepSeek / Zhipu GLM / custom OpenAI-compatible service) → fill in the API key and model name → save.

- The key lives only in app-private storage (DataStore) — never uploaded, never logged.
- The "Custom" option works with any service that speaks the OpenAI API protocol; just fill in `baseUrl` (including the `/v1` segment).
- Usage and cost estimates are visible on the AI Service page.

| Category | Source | Notes |
|------|------|------|
| Third-party API | `aihot.virxact.com` public API | AIHot Picks (Today's Hot + TOP20), AI Daily and archive |
| Third-party · live (partial) | HackerNews comments | Fetched live from the Firebase API inside the app; all source lists read archived snapshots |
| Third-party · archive | Companion data pipeline | Fetched in two daily batches (08:00 / 18:00 Beijing time; this repo's CI runs the evening batch at 18:17 — deliberately off the top of the hour to dodge GitHub schedule queueing) + AI-summarized + pushed to the [gitcode data repo](https://gitcode.com/peng1818/AI-News-Hub-Data) |

## 🤖 Data pipeline (optional)

If you need to run the data pipeline yourself (e.g. to deploy a private data source):

```bash
pip install -r scripts/requirements.txt

export AI_NEWS_HUB_AI_BASE_URL=...
export AI_NEWS_HUB_AI_MODEL=...
export AI_NEWS_HUB_AI_API_KEY=...
export GITCODE_TOKEN=...
export PRODUCT_HUNT_KEY=...                          # optional; if absent, that source is skipped

bash scripts/pipeline.sh
```

The pipeline is orchestrated by `scripts/pipeline.sh`; missing any hard-required env var exits immediately. A single-source failure doesn't affect the others — the `index.json` latest pointer is inherited from the last successful snapshot, so the client always gets valid data.

## ⚠️ Known limitations

- **Product Hunt is archive-only** — its Developer Token is a server-side secret that never enters the APK, so it always reads the pipeline's archived snapshots.
- **Translation needs a user-supplied key** — without an AI service configured, full-page and text-selection translation are unavailable (pre-generated content like summaries and Today's Hot is unaffected).
- **Archive failure does not fall back to live** — in archive mode a fetch failure shows an Error state directly; by design it does not auto-degrade.
- **The home widget has no error interaction** — on fetch failure it keeps the old data without clearing (the widget can't show an error state).
